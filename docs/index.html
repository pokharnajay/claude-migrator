Claude Migrator

Your Claude conversations did not disappear.
They are just filed under your old account.

A small macOS app that puts them back — and moves them between Macs.

Download for macOS

23 MB · Apple Silicon · macOS 11+ · free and open source · source on GitHub

What went wrong

Signing in to Claude with a different account empties the sidebar. It looks like the history was deleted. It was not.

Claude's desktop app keys its session storage by account UUID:

~/Library/Application Support/Claude/
  config.json                                        → lastKnownAccountUuid
  claude-code-sessions/<account>/<org>/local_*.json
  local-agent-mode-sessions/<account>/<org>/local_*.json

A new sign-in makes the app read a different <account> folder. The old one is still on disk — untouched, and unreachable. Claude Migrator copies it into the account you are actually signed in to.

Install

  1. Download the DMGOpen it, drag Claude Migrator into Applications.
  2. Allow the first launch

    The app is signed but not notarized by Apple, so macOS blocks it once. Open System Settings → Privacy & Security, scroll to the bottom, and click Open Anyway.

    Or in Terminal:

    xattr -dr com.apple.quarantine "/Applications/Claude Migrator.app"
  3. Quit ClaudeThe migrator refuses to write anything while Claude is running, because Claude holds these files open.

Nothing else to install — the app ships its own Python and Qt.

Restore history on this Mac

StepWhat happens
ScanRuns on launch. Reads the signed-in account and lists every other account on this Mac by e-mail, with session counts and date ranges. Writes nothing.
Back UpClones your entire Claude footprint to ~/Downloads/claude-backup-<timestamp>/, then verifies it file-by-file. Restore stays locked until verification passes.
Restore SessionsMerges the old account's sessions into the signed-in one.

Reopen Claude and the conversations are back in the sidebar.

Move history to another Mac

On the Mac that has the history

Tick the account, press Export Bundle…. You get a zip in ~/Downloads holding the sessions, the CLI transcripts they need in order to actually open, and a SHA-256 for every file.

On the other Mac

Install Claude Migrator, sign in to Claude, quit Claude, then press Import Bundle… and pick the zip. Everything merges into whichever account is signed in there. Anything already present is left alone.

One caveat. Sessions remember the folder they ran in. If that folder does not exist on the second Mac, the session still opens, but Claude will not find the project files. The import tells you exactly which ones.

What it will not do

This tool creates files. That is the whole surface area — no code path in it deletes or overwrites anything.

Never overwrites

Files are created with O_EXCL, so the existence check and the write are one atomic step. A file Claude writes at the same moment is left exactly as Claude wrote it.

Never half-writes

Session folders are staged and moved into place. The archive index is a set union written to a temp file and renamed.

Backup first, always

File counts and byte totals are compared per item. The restore button does not unlock until that passes.

Stays in its lane

A symlinked or oddly-named entry resolving outside the folder being migrated is refused outright.

Idempotent

Running anything twice is a no-op. The second pass finds nothing left to copy.

Offline by construction

No networking code, and Qt's network module is stripped from the build. Nothing leaves your Mac.

Imported bundles are treated as hostile

A zip from another machine is untrusted input, validated in full before anything is extracted — and rejected for absolute paths, .. traversal, symlink members, unexpected top-level directories, non-UUID workspace segments, file names that are not sessions or transcripts, a missing or future-versioned manifest, or zip-bomb signatures. Every surviving member is checksummed against the manifest and discarded on mismatch.

Build it yourself

git clone https://github.com/pokharnajay/claude-migrator.git
cd claude-migrator

python3 -m venv .venv-slim
.venv-slim/bin/pip install pyside6-essentials pyinstaller pytest

QT_QPA_PLATFORM=offscreen .venv-slim/bin/python -m pytest -q   # 105 tests
./build-app.sh      # → ~/Desktop/Claude Migrator.app
./build-dmg.sh      # → dist/ClaudeMigrator-<version>.dmg

Tests never touch real Claude data — they build a synthetic storage tree in a temp directory, including the hostile archives the importer has to refuse.
